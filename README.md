# 🌾 Rural Venture Navigator

### Empowering Rural Millet Entrepreneurs with Smarter Business Decisions

**Rural Venture Navigator** is a digital platform designed to help rural millet entrepreneurs understand their business performance, evaluate customer demand, and make informed decisions using cost analysis, customer feedback, and personalized business recommendations.

> From calculating product costs to understanding customer preferences — helping small rural businesses take their next step with confidence.

---

## ✨ Why Rural Venture Navigator?

Small rural entrepreneurs often make business decisions without clear information about production costs, customer preferences, or market demand.

Rural Venture Navigator brings these insights together in one accessible platform.

## 🚀 Key Features

### 1. 💰 Smart Cost Calculator
- Calculate product production costs.
- Understand expenses such as raw materials, labour, packaging, and shipping.
- Evaluate product-level cost and profitability.

### 2. 📊 Customer Feedback System
- Collect customer reviews and ratings.
- Understand product satisfaction and buying preferences.
- View feedback through a dedicated dashboard.

### 3. 🤖 AI-Assisted Business Recommendations
- Generate personalized business guidance.
- Use business and customer insights to support better decisions.
- Get actionable suggestions for the next stage of growth.

### 4. 🎯 Business Decision Support
- Evaluate business performance.
- Understand whether a product needs improvement or further testing.
- Make more informed business decisions.

### 5. 🌐 Multilingual & Voice-Friendly Experience
- Language support for easier accessibility.
- Voice-friendly interactions for a simpler user experience.

## ⚙️ Getting Started

### Prerequisites
- Node.js and npm
- MongoDB (optional when using the local JSON fallback)

### 1. Clone the repository

```bash
git clone https://github.com/bhoomi12er-oss/rural-venture-navigator.git
cd rural-venture-navigator
```

### 2. Install frontend dependencies

```bash
cd client
npm install
npm run dev
```

### 3. Start the backend

Open another terminal:

```bash
cd server
npm install
npm run dev
```

Configure the backend environment variables according to the server configuration before running it. Keep credentials in `.env`; never commit secrets.

The backend also includes a local JSON storage fallback when MongoDB is unavailable.
